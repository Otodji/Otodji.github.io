# otodji.github.io

Personal portfolio of **Théophile Otodji**: data science, machine learning and probability distribution theory.

Live site: **https://otodji.github.io**

A single static page (`index.html`, no build step) hosted on GitHub Pages.
To add a downloadable CV, place a file named `cv.pdf` at the root of this repository:
the "Download CV" button appears automatically once the file exists.
