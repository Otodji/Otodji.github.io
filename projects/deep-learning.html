Starting point

One computational graph

Everything starts from a tiny graph on \(N \times D\) matrices, differentiated by hand and then automatically:

$$a = x \odot y, \qquad b = a + z, \qquad c = \sum_{i,j} b_{ij} \qquad\Longrightarrow\qquad \frac{\partial c}{\partial x} = y, \quad \frac{\partial c}{\partial y} = x, \quad \frac{\partial c}{\partial z} = \mathbf{1}$$

The same idea then scales up to a two-layer network, custom autograd functions, and a full image classifier.

Takeaway

Key insight: frameworks build the computational graph and automate backpropagation, so you only describe the forward pass. Predefined layers, losses and optimizers then make models short and readable.

Code

The PyTorch training step

import torch

model = torch.nn.Sequential(
    torch.nn.Linear(D_in, H),
    torch.nn.ReLU(),
    torch.nn.Linear(H, D_out),
)
optimizer = torch.optim.Adam(model.parameters(), lr=1e-4)

for t in range(500):
    y_pred = model(x)                                   # forward pass builds the graph
    loss = torch.nn.functional.mse_loss(y_pred, y)
    optimizer.zero_grad()
    loss.backward()                                     # autograd computes every gradient
    optimizer.step()                                    # one gradient-descent update
