The problem

Modelling lifetimes and inequality

Lifetime data, such as the time before a component fails, are often right-skewed with heavy tails. The NTLKwIEx distribution combines the Topp-Leone, Kumaraswamy and inverse exponential constructions to cover a wide range of shapes with only five parameters.

The model was introduced in AIP Advances (2024), together with inequality measures and applications to socio-economic development indicators. The package makes all of it reproducible in R.

The model

Distribution function

With \(K(x) = e^{-\theta / x}\) for \(x > 0\) and \(\theta, \alpha, a, b, m > 0\):

$$F(x;\theta,\alpha,a,b,m) = \Big[\,1-\big(1-K(x)^{\,a\,\alpha^{K(x)}}\big)^{2b}\Big]^{m}$$
Try it

Interactive density explorer

Move the sliders to reshape the distribution. Quantiles are computed numerically, exactly like Q_NTLKwIEx does. With the default parameters, the median is 1.991, the value printed in the package documentation.

Ships with the ConductorFailureTimes dataset (failure times, in hours, of 59 conductors from an accelerated life test) and a vignette.

Quick start

From install to fitted model

install.packages("NTLKwIEx")
library(NTLKwIEx)

# Density, cumulative probability and median
P_NTLKwIEx(2, teta = 2, alpha = 0.5, a = 1, b = 1, m = 2)   #> 0.3427294
C_NTLKwIEx(2, teta = 2, alpha = 0.5, a = 1, b = 1, m = 2)   #> 0.5029632
Q_NTLKwIEx(0.5, teta = 2, alpha = 0.5, a = 1, b = 1, m = 2) #> 1.99138

# Fit the model to conductor failure times
data(ConductorFailureTimes)
E_NTLKwIEx(ConductorFailureTimes)
Sim_NTLKwIEx(ConductorFailureTimes)
